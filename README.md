# grapevine

Lightweight reactive dependency injection framework for TypeScript.

## Version Control

This repository uses [Jujutsu](https://github.com/martinvonz/jj) (`jj`) for version control, colocated with Git.

- [`.eslintrc.yml`](.eslintrc.yml): ESLint configuration extending devbase rules.

- [`.mk.config.js`](.mk.config.js): Legacy mk build tool configuration.
- [`.prettierignore`](.prettierignore): Prettier ignore file list.
- [`.prettierrc.yml`](.prettierrc.yml): Prettier formatting configuration.
- [`LICENSE`](LICENSE): MIT license terms.
- [`README.md`](README.md): Directory documentation for the grapevine package root.
- [`TODO`](TODO): Project task and backlog tracking.

- [`package-lock.json`](package-lock.json): NPM dependency tree lockfile.
- [`package.json`](package.json): NPM package manifest and dependencies.
- [`tsconfig.json`](tsconfig.json): TypeScript compiler configuration.
- [`webpack.config.js`](webpack.config.js): Webpack bundler configuration.
